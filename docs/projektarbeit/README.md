## Arbeitsregeln

- **Verlinken statt kopieren.** Die Fachdokumente in `docs/` bleiben die Quelle. Die Kapitel fassen zusammen und begründen.
- **Jedes Kapitel hat eine Person, die es verantwortet.** Mitschreiben dürfen alle; Änderungen an fremden Kapiteln kurz im Team ansagen.
- **Zahlen nur mit Herkunft.** Jede Zahl ist entweder belegt (Interview, Messung, Quelle) oder als *Annahme* markiert.
- **Keine echten Patientendaten**, die Praxis bleibt anonym.
- Bearbeiten geht direkt auf GitHub im Browser (Stift-Symbol), Markdown reicht.
- Offene Punkte stehen in jedem Kapitel unter „Lücken“. Wer eine Lücke schließt, streicht sie dort.
